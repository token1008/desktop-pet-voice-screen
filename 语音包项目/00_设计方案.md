# 桌宠语音包替换设计方案（已获用户批准 2026-11-07）

作者：Sngels_wyh 桌宠小狗（V1.2.0 电路板）· 语音模块 SU-03T1 · 主控 STM32F103C8T6

## 目标
替换默认机械音 TTS，制作并烧录两份角色语音包：
- 🎭 芙宁娜包（原神）— 唤醒词「芙宁娜大人」，戏剧化傲娇
- 🌠 流萤包（崩坏星穹铁道）— 唤醒词「流萤大人」，温柔元气带机甲感

## 核心架构结论
SU-03T1 → UART(9600) → STM32 的动作协议保持 **0x29~0x50 单字节** 不变：
- STM32 固件**不需要**重新烧录，蓝牙控制不受影响
- 仅重烧 SU-03T1（UniOneUpdateTool，固件必须带 `_update` 后缀）
- 两套固件 bin，换角色 = 重烧一次 SU-03T1

## 音色管线
1. B站原声视频 → yt-dlp 下载 → ffmpeg 截取 10~20s 干净独白（无BGM/无混响）
2. 百炼声音复刻克隆音色（复刻免费）
3. 台词批量合成（每包 23 条：唤醒回复3 + 命令回复20）
4. ffmpeg 转 16kHz 单声道 wav（按平台要求调整）

## 烧录流程（官方 PDF 已确认）
接线：B7引脚↔串口RXD，B6引脚↔串口TXD，GND↔GND（升级模式接线）
步骤：UniOneUpdateTool.exe 选择 `_update.bin` → 点烧录（设备不上电）→ 上电自动下载 → 完成自动重启
注意：镜像必须带 `_update` 后缀，否则烧后无法开机；USB升级占64KB flash，开机+20ms

## 风险与对策
- 模块音频空间有限 → 台词 ≤4秒/条，超限则精简次要回复
- 平台回复若仅支持TTS文本 → 备用方案：选平台音色列表最接近音色+文本台词
- 命令词识别率 → 触发词保留原直白词，角色化变体谨慎添加
- 版权 → 克隆音色仅供个人桌宠使用，不可商用
